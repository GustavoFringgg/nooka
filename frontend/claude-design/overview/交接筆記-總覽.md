# 總覽頁交接筆記 → Nuxt 4 實作

設計檔：`Nooka 儀表板.dc.html`（直接開啟瀏覽器看效果，右上角按鈕可切換未登入／已登入兩種狀態）。此檔是設計預覽工具產物，請依下方規格用 Vue/Nuxt 慣例重寫。

## 對應到現有檔案
- 新頁面，建議路徑 `frontend/app/pages/overview.vue`（或依實際路由規劃）
- `frontend/app/components/AppNav.vue` — nav 需與首頁/練習頁同步（見下方，nav 用的是首頁那套暖紙色 tokens，不是下面這組）
- 內容區塊（bento 網格）用的是另一套設計系統的 tokens，不是首頁那套。實際數值如下 —— 這份 CSS 檔沒有一起匯出，請直接把下面的值當作 source of truth 手動對應，或建成一組獨立的 CSS 變數：

```css
/* 總覽頁內容區專用 tokens（跟首頁/練習頁的暖紙色是兩套系統，只有 nav 共用首頁那套） */
--ov-color-bg: #f5ead8;
--ov-color-surface: #ebddc5;      /* 卡片底色 */
--ov-color-text: #201e1d;
--ov-color-accent: #c67139;       /* 主強調色（赤陶橘系） */
--ov-color-accent-2: #7a8a5e;     /* 次強調色（sage 綠） */

--ov-color-accent-100: #fff2eb;   /* 淺色卡背景 */
--ov-color-accent-200: #ffe1d0;   /* 裝飾圓形 */
--ov-color-accent-700: #8c491a;   /* 深色卡上的強調文字 */

--ov-color-accent-2-100: #f0fae1; /* sage 淺色卡背景 */
--ov-color-accent-2-500: #8fa073;
--ov-color-accent-2-700: #56633f;

--ov-color-neutral-200: #eee7db;  /* 進度條底色 */
--ov-color-neutral-700: #645c50;  /* 次要文字 */
--ov-color-neutral-900: #2e2b25;  /* 深色卡背景（每日一字卡） */

--ov-font-heading: "Caprasimo", system-ui, sans-serif;  /* 標題字體 — 不是 Newreader，是這個較粗圓潤的 slab serif */
--ov-font-body: "Figtree", system-ui, sans-serif;

--ov-space-1: 4.4px; --ov-space-2: 8.8px; --ov-space-3: 13.2px;
--ov-space-4: 17.6px; --ov-space-6: 26.4px; --ov-space-8: 35.2px;

--ov-shadow-md: 0 3px 10px color-mix(in srgb, #2e2b25 16%, transparent);
```

Google Font：`Caprasimo` + `Figtree`（`@import url('https://fonts.googleapis.com/css2?family=Caprasimo:wght@400&family=Figtree:wght@400;600;700&display=swap')`）。

卡片一律**無邊框**、大圓角（16px 或更大）、輕微陰影，不是描邊樣式。按鈕：主要動作（nav 的登入按鈕）用 primary 綠（首頁那套 `#3C5A44`），但總覽頁內容區裡的「登入/註冊」CTA 按鈕應該用這套的 accent 橘 `#c67139`，兩者故意不同色，不要統一成綠色。

## Nav（三頁共用）
順序：**首頁 / 總覽 / 練習 / 學習紀錄 / 登入**，這頁 active 在「總覽」。padding `22px 48px`，底部 1px 邊框，最右「登入/註冊」或已登入時顯示登出，實心藥丸按鈕樣式同首頁。

## 頁面用途
不是個人學習歷程明細（那是「學習紀錄」），這頁是「網站有多少資料可以學」的總覽 + 登入後的個人摘要。

## 版面：Bento 不對稱網格（桌面），760px 以下收成單欄
```
┌─────────────────────┬──────────┐
│  單字庫總數（大卡）    │ 主題書架  │
│                      │（圓形數字）│
├──────────┬───────────┴──────────┤
│ 每日一字  │      每日一句          │
│（深色卡） │                       │
├──────────┴───────────────────────┤
│ 登入狀態 / 已學數量  │ 最容易忘記的5字 │
└───────────────────────────────────┘
```
- 單字庫總數卡：暖橘底 + 右上角圓形裝飾，數字從 0 動態數到目標值（1.4s ease-out-cubic，`requestAnimationFrame`），目前示範值 1,240
- 主題書架卡：sage 綠底，圓形徽章顯示數字（目前 6），置中對齊
- 每日一字卡：深色卡（`--color-text` 底、`--color-bg` 字），顯示單字/中文意思/詞性
- 每日一句卡：淺卡，顯示英文例句 + 中文翻譯
- 未登入：CTA 卡「看看你的學習狀況」+ 登入按鈕；下方「最容易忘記的字」清單整塊 `opacity:.5; filter:blur(1.5px)` 模糊預覽，不可互動
- 已登入：「你已經學了 N 個」統計卡（sage 底）+ 最容易忘記的 5 個字清單（單字/中文/依錯誤次數等比例的橫條圖/錯誤次數 tag）

## 資料結構
```js
// 全站
{ totalWords: 1240, totalBooks: 6 }
// 每日
{ dailyWord: "haltingly", dailyMeaning: "吞吞吐吐地", dailyPos: "adv.",
  dailyQuoteEn: "He explained the accident haltingly, still shaken.",
  dailyQuoteZh: "他吞吞吐吐地說明了這場事故，還處於驚嚇中。" }
// 已登入用戶
{ userLearned: 182,
  weakWords: [
    { word: "haltingly", meaning: "吞吞吐吐地", misses: 6, pct: 90 },
    { word: "vicarious", meaning: "替代的感受", misses: 5, pct: 74 },
    { word: "hectic", meaning: "忙亂的", misses: 4, pct: 60 },
    { word: "hub", meaning: "中心樞紐", misses: 3, pct: 44 },
    { word: "handout", meaning: "講義；施捨", misses: 2, pct: 28 }
  ] }
```
`pct` = 該字錯誤次數相對最大值的比例，用來畫橫條長度。

## 注意事項（實作時容易踩的坑，這裡都修過）
- 用了設計系統的間距 token 時，注意該系統實際存在哪些 `--space-*` 數值，缺一個會直接讓 gap/padding 塌陷成 0
- bento 卡片若用元件庫自帶的 `.card`（本身可能內建 `flex-direction:column`），要蓋掉方向時記得處理特異度（必要時用更具體選擇器，不要濫用 !important）
- 響應式：760px 以下整個 bento 網格改單欄，順序維持「總數→書架→每日一字→每日一句→狀態→弱項清單」

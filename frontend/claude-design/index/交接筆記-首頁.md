## Design tokens
```css
--color-bg: #F7F2E9;        /* 主背景 */
--color-bg-alt: #F0E9D8;    /* 深一階色帶，區塊交錯用 */
--color-text: #2B2A25;
--color-text-muted: #6B6558;
--color-primary: #3C5A44;   /* 深綠，主要按鈕/強調 */
--color-accent: #C1653B;    /* 赤陶橘，次強調/hover */
--font-heading: 'Newreader', serif;  /* 標題，斜體用於強調字 */
--font-body: 'Work Sans', 'Noto Sans TC', sans-serif;
```
Google Fonts: `Newreader:ital,wght@0,400;0,500;1,400;1,500` + `Work Sans:wght@400;500;600`。

## Nav（三頁共用，需與練習頁、儀表板一致）
順序：首頁 / 里程碑 / 練習 / 學習紀錄 / 登入，最右「免費開始」實心藥丸按鈕（`--color-primary` 底，hover 變 `--color-accent`）。目前頁面用底線標示 active 項目。padding `22px 48px`，底部 1px 邊框 `rgba(43,42,37,.15)`。

## 頁面結構（由上到下 6 層，背景交錯 bg/bg-alt）
1. **Hero**（bg）：左文字（標籤 pill + H1 + 說明 + 兩顆 CTA），右側卡片牆（三張堆疊卡片，中間一張顯示當前單字，每 2.6 秒輪替一次，來源是種子單字陣列）
2. **先選書**（bg-alt）：左文字，右側書架跑馬燈——10 個書脊色塊（5 款樣式各出現兩次做無縫循環），CSS `translateX` 動畫向左持續滾動，左右邊緣用 `mask-image` 漸層裁切
3. **挑練習方式**（bg）：三張卡片（單字卡／選擇題／打字拼寫），選擇題標「推薦先玩這個」+ 實線強調邊框，其餘兩個未上線
4. **答錯詳解**（bg-alt）：左側並排兩張卡（你選的錯誤答案 + 正解，各含詞性/中文/英文定義/例句），右文字說明
5. **為什麼會記得住**（bg）：左文字說明 SM-2 演算法，右側 SVG 遺忘曲線圖（橘線代表遺忘、綠點代表每次答對後記憶被拉高，時間軸：明天/4天後/2週後/1個月後）
6. **收尾 CTA + footer**（bg-alt）：「先練六個字，看看有沒有感覺」+ CTA 按鈕 + footer（品牌 + © 2026）

## 互動細節
- Hero 卡片牆：中間卡片內容輪替（非翻牌），左右兩張是靜態旋轉裝飾卡
- 書架跑馬燈：純 CSS `@keyframes` 位移，非使用者互動
- 所有按鈕：hover 有 `transform: translateY(-2px)` 或 `scale(1.03)` + 顏色過渡，過渡時間 .2~.25s

## 版面結構（由上到下）
1. 標題「先選一本書」+ 說明文字（`max-width:1040px` 置中，不跟下方書架同寬）
2. `<hr>` 分隔線
3. 三個練習方式按鈕（單字卡 / 選擇題 / 打字拼寫），單字卡與打字拼寫呈灰階不可點+「即將推出」標示；選擇題可點擊，未選書時也是灰階不可點
4. 主體雙欄（`max-width:1440px`，比例 1.15 : 0.85）：
   - **左欄：書架網格**（2 欄），書本卡片是「書本造型」：左側書脊色塊 + 右側封面色塊，封面右緣模擬書頁邊緣紋理（`repeating-linear-gradient`），選中的書會上浮 `translateY(-10px) rotate(-1.5deg)` 並在右上角出現書籤旗標（三角缺口色塊）。書架超過 6 本時該欄自帶 `overflow-y:auto`（`height:598px`），書架與右側單字預覽欄高度需一致（都用 `height` 而非 `max-height`，且 `box-sizing:border-box`，兩者 padding-top 都對齊為 28px，避免書籤被裁切、避免兩欄底部對不齊）
   - **右欄：單字預覽面板**（sticky，`height:598px` 與左欄等高）：跟隨左側選中的書即時切換內容——書名（Newreader 26px + 色塊圓角方塊）+ 該書單字數/已練數，下方是 2 欄小卡網格展示該書單字（demo 用 20 筆），每張詞條式小卡（無底色塊，改用 `border-bottom` 細線分隔，字典排版感）：
     - 左上：英文單字（Newreader 17px）
     - 右上：中文意思
     - 左下：KK 音標（等寬字體 `ui-monospace`/`SF Mono`），右側緊鄰一個圓形喇叭發音按鈕（icon 15px，常駐淡灰色，hover 變深綠 `#3C5A44` + 淺底色）
     - 右下：詞性 pill（動詞/名詞/形容詞/副詞，四種各自配色，見下方 tokens）

## 發音按鈕（僅視覺，功能未接）
按鈕已放在音標右側，尚未接技術棧。建議方案二選一：
- MVP：瀏覽器原生 Web Speech API（`SpeechSynthesisUtterance`），免費、免存音檔，但機器音
- 正式：TTS 服務（Google/Azure/ElevenLabs）預先批次生成音檔存 CDN，`<audio>` 播放，音質更好但需維護音檔庫
點擊時建議 icon 有短暫變色/放大回饋，播放中可切換成靜音圖示避免使用者重複點擊誤解沒反應。

## 選書 → 開始練習彈窗
點擊「選擇題」（需先選書）跳出彈窗，內容：
- 左欄：練習方向單選（看英文選中文 / 看中文選英文）
- 右欄：對應方向的簡易動畫預覽（EN/中文卡片 + 箭頭 + 三條選項列表，中間高亮），欄位需固定 `min-height:112px` 避免切換時彈窗高度跳動
- 下方：題目數量滑桿，`min`/`max` 依所選書的單字量動態決定（`step="1"`，避免單字量少的書 step 太大導致無法拖曳）
- 底部：取消 / 開始練習按鈕

## 種子資料（範例，實際應接 API）
```js
books = [
  { id:"toeic", name:"多益(600)", color:"#b08434", spineColor:"#8a6425", count:6, done:3 },
  { id:"security", name:"資安用", color:"#9c4a3c", spineColor:"#78392e", count:40, done:0 },
  // ...共 9 本，顏色各異，spineColor 需比 color 深一階
]
```
單字資料需含 `en / zh / pos（詞性）/ ipa（KK音標）`，排序（A-Z 或其他規則）交由後端 API 處理，前端不用額外排序邏輯。
